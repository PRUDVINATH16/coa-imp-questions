Q1. Need for Memory Interleaving + Block Transfer Calculation (5 Marks)

1. Need for Memory Interleaving

  • Main memory is much slower than the CPU, causing the processor to remain idle during memory accesses.
  • If memory is organized as a single module, a block transfer accesses only one module at a time → sequential access.
  • Interleaving divides main memory into multiple independent modules, each with its own ABR (Address Buffer Register) and DBR (Data Buffer Register).
  • Consecutive addresses are distributed across different modules, allowing parallel access and increasing the aggregate data transfer rate.

2. Conventional vs. Interleaved Addressing

(a) Conventional Addressing

Address layout: [ High-order k bits : Module ] [ Low-order m bits : Word ] Consecutive addresses: Address 0 → Module 0 Address 1 → Module 0 Address 2 → Module 0 Address 3 → Module 0 → Only ONE module is active at a time.

(b) Interleaved Addressing

Address layout: [ High-order m bits : Word ] [ Low-order k bits : Module ] Consecutive addresses: Address 0 → Module 0 Address 1 → Module 1 Address 2 → Module 2 Address 3 → Module 3 Address 4 → Module 0 → Consecutive locations use SUCCESSIVE modules → Parallel access.
Exam Tip: Draw two simple blocks side-by-side. Left block: all arrows pointing to M0 (Conventional). Right block: arrows alternating to M0, M1, M2, M3 (Interleaved).

3. Block Transfer Time Calculation (8-word cache block)

Given timing:

  • Address transmission = 1 cycle
  • First memory word = 8 cycles
  • Each subsequent word = 4 cycles
  • Transfer one word to cache = 1 cycle

Case (a) Single Module (Conventional)

All 8 words come sequentially from the same module:

T = 1 + 8 + (7 × 4) + 1 T = 1 + 8 + 28 + 1 T = 38 cycles

Case (b) Four-Way Interleaved Memory

4 modules fetch 4 words in parallel, while the first 4 words are transferred to cache:

T = Address (1) + First word (8) + Transfer 4 words (4) + Fetch next 4 (4) T = 1 + 8 + 4 + 4 T = 17 cycles
✅ Conclusion: Interleaving reduces block transfer time from 38 cycles to 17 cycles, significantly increasing memory throughput.
