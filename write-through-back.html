Q6. Write-Through vs. Write-Back Cache Policies & Write Buffer (5 Marks)

1. Write-Through Policy

  • On a write hit, the cache block and main memory are updated simultaneously.
  • Data consistency: High — main memory always holds the latest value.
  • Memory traffic: High — every write goes to main memory, even if the same block is written repeatedly (e.g., inside a loop).
  • Performance: Lower — frequent memory writes slow down execution. Simple to implement.

2. Write-Back Policy

  • On a write hit, only the cache block is updated and a dirty (modified) bit is set.
  • The block is written to main memory only when it is replaced (evicted) from the cache.
  • Data consistency: Temporarily lower — main memory may hold stale data until the dirty block is written back. The dirty bit tracks this.
  • Memory traffic: Low — multiple writes to the same block result in only one memory write (on eviction).
  • Performance: Higher — writes occur at cache speed, and memory bandwidth is saved.

3. Comparison Table

Parameter Write-Through Write-Back
Data Consistency High (memory always current) Lower (memory may be stale until eviction)
Memory Traffic High (every write goes to memory) Low (writes only on block replacement)
Performance Lower Higher
Implementation Simple Needs dirty bit

4. Role of a Write Buffer

  • In a write-through cache, every write goes to slow main memory. If the CPU waits for each write to complete, performance drops.
  • A write buffer is a small FIFO queue between the cache and main memory.
  • The CPU places the write request in the buffer and immediately continues execution; the buffer sends the data to main memory later.
  • Read requests get priority. If a read address matches an entry in the write buffer, the data is read from the buffer (not stale main memory).
  • In a write-back cache, a write buffer temporarily holds the dirty block while the new block is fetched, so the CPU does not wait for the write-back.
✅ Summary: Write-through is simple and ensures high consistency but generates high memory traffic. Write-back is faster and generates less traffic but needs a dirty bit. A write buffer hides the latency of write-through writes, allowing the CPU to continue without waiting for main memory.
