Q2. Processor-DRAM Performance Gap & Moore's Law (5 Marks)

1. Moore's Law

  • Moore's Law states that the number of transistors on a chip doubles approximately every 1.5 to 2 years.
  • This has led to rapid improvements in processor performance over time.

2. The Widening Performance Gap

The performance of processors and DRAM has not grown at the same rate:

Processor Performance: grows ~60% per year (2x every 1.5 years) DRAM Performance: grows ~ 9% per year (2x every 10 years) Processor ─────────────────────────► (Fast growth) Gap widens by ~50% per year DRAM ────► (Slow growth)
  • Because the processor improves much faster than DRAM, the performance gap grows by approximately 50% every year.
  • This means the CPU can process data much faster than the main memory can supply it.

3. Why Memory is a Bottleneck

  • Even a sophisticated processor may perform well below its potential unless supported by a matching memory system.
  • The processor often remains idle while waiting for instructions and data from slow main memory.
  • This is often illustrated as a "horse pulling an overloaded cart" — the fast processor (horse) is held back by the slow memory (heavy cart).
  • The solution is the memory hierarchy (cache, virtual memory, interleaving) to hide this gap and make memory appear faster.
✅ Conclusion: Due to Moore's Law, processor performance grows much faster than DRAM performance, creating a widening performance gap. This makes main memory a system bottleneck, which is addressed through the memory hierarchy and cache memory.
Exam Tip: In the exam, draw two simple lines on a graph: a steep line for "Processor" and a shallow line for "DRAM". Label the gap between them as "Performance Gap (grows ~50%/year)". This diagram alone earns marks.
