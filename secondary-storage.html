Q9. Magnetic Disks & RAID Levels (5 Marks)

1. Role of Magnetic Disks

  • Provide large-capacity, non-volatile, low-cost secondary storage.
  • Used for storing programs, files, and data that do not fit in main memory.
  • Access is mechanical, so it is much slower than semiconductor memory.

2. Physical Structure

┌──────────────┐ │ Spindle │ ← rotates all platters together └──────┬───────┘ ┌──────────┼──────────┐ │ Platter │ Platter │ (magnetic film on each surface) └──────────┼──────────┘ │ Read/Write Head (one per surface, moves radially)
  • Platters: Rotating disks with a magnetic film on each surface.
  • Read/Write Head: One per surface; moves radially to the required track.
  • Tracks: Concentric circles on each surface.
  • Sectors: Tracks are divided into sectors (typically 512 bytes of data).
  • Cylinder: The set of corresponding tracks on all surfaces.
  • Access specification: Surface, Track, Sector.

3. Performance Parameters

(a) Seek Time

Time to move the read/write heads to the required track. Typically 5–8 ms.

(b) Rotational Latency

Time waiting for the desired sector to rotate under the head. Average latency ≈ half a rotation:

T_latency = ½ × T_rotation

(c) Disk Access Time

T_access = T_seek + T_rotational_latency

For small transfers, access time is often much larger than the actual data-transfer time.

4. RAID Levels

RAID 0 — Striping

  • Data is divided into strips and distributed across multiple disks.
  • Goal: Higher performance (parallel transfer).
  • Reliability: None — failure of one disk loses the entire array's data.

RAID 1 — Mirroring

  • Every logical strip is duplicated on a mirror disk.
  • Goal: High reliability.
  • Cost: 100% storage overhead (need 2N disks for N disks of data).
  • Recovery is simple: copy the surviving disk.

RAID 5 — Distributed Parity

  • Data and parity strips are distributed across all disks (no dedicated parity disk).
  • Goal: Balanced performance and reliability.
  • Can recover from one disk failure using XOR parity.
  • Avoids the parity-disk bottleneck of RAID 4.

5. RAID Comparison Table

Level Main Idea Goal Fault Tolerance
RAID 0 Striping Performance None
RAID 1 Mirroring Reliability 1 disk
RAID 5 Distributed parity Both (balanced) 1 disk
✅ Summary: Magnetic disks provide large, non-volatile storage; their access time is dominated by seek time and rotational latency. RAID combines multiple disks to improve performance (RAID 0), reliability (RAID 1), or both (RAID 5).
