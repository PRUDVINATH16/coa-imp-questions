Q3. Cache Memory & Mapping Techniques (5 Marks)

1. What is Cache Memory?

  • Cache is a small, fast memory placed between the processor and main memory.
  • It exists because the processor is much faster than main memory, causing the CPU to remain idle while waiting for data.
  • It stores frequently or recently used data/instructions, exploiting locality of reference (temporal and spatial).
  • On a memory access, the CPU checks the cache first: Hit → data from cache; Miss → block fetched from main memory into cache, then supplied to CPU.

2. Mapping Techniques

Mapping functions determine how memory blocks are placed in the cache.

(a) Direct Mapping

  • Each main-memory block maps to exactly one cache block.
  • Rule: Cache Block = Memory Block mod Number of Cache Blocks.
  • Address fields: Tag | Block | Word
  • Advantage: Simple and inexpensive to implement.
  • Disadvantage: Multiple blocks may compete for the same cache location (conflicts), causing frequent replacements even if the cache is not full.

(b) Associative (Fully Associative) Mapping

  • A memory block can be placed in any cache block.
  • Address fields: Tag | Word
  • Operation: The tag is compared with the tags of all cache blocks using a parallel associative search.
  • Advantage: Complete flexibility, better utilization of cache space, fewer conflicts.
  • Disadvantage: Higher hardware cost (comparators for every block).

(c) Set-Associative Mapping

  • Cache blocks are grouped into sets. A memory block maps to one specific set but can occupy any of the \(k\) positions within that set.
  • \(k\)-way set-associative: each set contains \(k\) cache blocks.
  • Address fields: Tag | Set | Word
  • Advantage: Combines the low cost of direct mapping with the flexibility of associative mapping. The tag is compared with only \(k\) blocks per set.
Direct: [ Tag | Block | Word ] Associative: [ Tag | Word ] Set-Associative: [ Tag | Set | Word ]

3. Best Trade-off

✅ Set-Associative mapping provides the best trade-off between hit ratio and implementation cost. It reduces the conflict misses of direct mapping while avoiding the high hardware cost of a full associative search. It gives medium flexibility at a medium cost.
Exam Tip: For each technique, write the mapping rule and the address field format. This is the easiest way to score full marks.
