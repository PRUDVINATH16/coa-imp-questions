Q7. AMAT for Read and Write Requests (Write-Through, 5 Marks)

Given Data

  • Cache access time (\(C\)) = 50 ns
  • Main memory access time (\(M\)) = 300 ns
  • Read requests = 75% (0.75); Write requests = 25% (0.25)
  • Read hit ratio (\(h\)) = 0.8
  • Write-through scheme: cache and main memory updated in parallel

Step 1: AMAT for Read Requests

On a hit, only cache is accessed. On a miss, cache is checked, then main memory is accessed.

T_read = h × C + (1 − h) × (C + M) T_read = 0.8 × 50 + 0.2 × (50 + 300) T_read = 40 + 0.2 × 350 T_read = 40 + 70 T_read = 110 ns

Step 2: AMAT for Write Requests

In write-through with parallel updating, the cache and main memory are written simultaneously. The CPU must wait for the slower of the two (main memory), since main memory is the bottleneck unless a write buffer is used.

T_write = M = 300 ns

Step 3: Overall AMAT

T_avg = (0.75 × T_read) + (0.25 × T_write) T_avg = (0.75 × 110) + (0.25 × 300) T_avg = 82.5 + 75 T_avg = 157.5 ns
✅ Final Answer:
AMAT for Reads = 110 ns
AMAT for Writes = 300 ns
Overall AMAT = 157.5 ns
Exam Tip: State the assumption clearly: "In write-through without a write buffer, the write time equals main memory access time because the CPU waits for memory to complete." This secures full marks.

Q8. AMAT and Speedup due to Cache (5 Marks)

Given Data

  • Hit ratio (\(h\)) = 0.75
  • Cache access time (\(C\)) = 10 ns
  • Main memory access time (\(M\)) = 110 ns

Step 1: Average Memory Access Time (AMAT)

AMAT = h × C + (1 − h) × (C + M) AMAT = 0.75 × 10 + 0.25 × (10 + 110) AMAT = 7.5 + 0.25 × 120 AMAT = 7.5 + 30 AMAT = 37.5 ns

Step 2: Time Without Cache

Without cache, every access goes to main memory:

T_without = M = 110 ns

Step 3: Speedup

Speedup = T_without / T_with Speedup = 110 / 37.5 Speedup ≈ 2.93
✅ Final Answer:
AMAT = 37.5 ns
Speedup ≈ 2.93× (cache makes memory access about 2.93 times faster)
Exam Tip: Always state the formula first. Show the substitution clearly. The speedup is a simple ratio — do not overcomplicate it.

Reference: M3.pdf, Pages 51–54 — "Hit Rate and Miss Penalty" and "Average Memory Access Time".
